# 奥特自走棋：双赛季网页

第一赛季 59 名棋子，第二赛季 60 名棋子。一名玩家与七名 AI 对战；两个赛季的规则、卡池及存档分别保存。

页面入口：

- 第一赛季整局：`?mode=match`
- 第二赛季整局：`season2/`
- 第一赛季战斗实验场：根目录。

上传时将此目录的全部内容放在 GitHub Pages 发布目录，保留 `season2/` 与 `assets/` 的目录结构。无需编译，也无需上传本机 FLAC 原件。

2026-10-08 更新：

- 装备拖放预览配方、松手合成；保留给棋子穿戴装备的操作。
- 改进 AI 购卡、合星、羁绊、站位和装备分配；选秀随阶段提高价值，并展示八人领取过程。
- 两季野怪共用掉落规则：同局同回合统一组件数量、战利品球档次和奖励预算，具体内容可以不同。击败相应野怪才能领取；未获得的组件留待后续野怪回合补发。
- 早期只出现普通奖励；后期巨兽携带并掉落成装。奖励棋子实际占用公共卡池，结算与刷新不会重复发放。
- 大厅包含24首完整音乐，仅显示播放状态，提供上一首、下一首、播放／停止和音量。两季共享音乐设置。

本地启动（在完整开发工程根目录执行）：

```powershell
node scripts/serve-autochess.mjs 8791
node --test tests/autochess*.test.mjs
```

自动回归与 Edge 浏览器实测记录位于开发工程 `docs/design/ultra-autochess/`。尚需玩家试玩确认掉落节奏、AI 难度与组合平衡；测试通过不代表竞技平衡已经完成。
